# Raw Recordings and Transcripts

Place temporary meeting audio/video and unreviewed transcription output here.

Raw media formats are intentionally ignored by Git. Meeting recordings can contain personal or sensitive information and can also be too large for a normal Git repository.

Before moving material to `../Meeting_Minutes/`:

- confirm that recording consent was obtained;
- verify the transcript against the audio;
- correct speaker labels and technical terminology;
- extract decisions, action owners, and deadlines;
- clearly mark unresolved or uncertain statements;
- remove information that should not be retained in the project repository.
