`evaluate_results()` retains technical energy and feasibility metrics. Annual cost is available only with explicit import/export tariffs and a complete calendar year or justified seasonal representative-day weights. `capital_recovery_factor()` annualizes initial CAPEX; fixed O&M is a fraction of initial CAPEX. Terminal SOC equality prevents free initial energy; explicitly priced terminal energy is supported for full-year configurations. Monetary components and initial CAPEX have separate labels.
