GA, GWO and exhaustive search share `SimulationEvaluator` and `annual_economic_objective`. The objective is annual ownership + grid purchases − export credits + distinct curtailment and shedding penalties, in USD/year. Infeasible candidates score infinity. Net annual export revenue can yield negative cost. Search update rules and rule-based dispatch are unchanged. The GUI compares an identical-input no-BESS baseline and permits selecting no storage.
