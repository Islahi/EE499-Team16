Use the Designer desktop and folder/clock/window workflow in [the application instructions](../../README.md). Historical and forecast profiles remain separate. Power flow is fixed to Numba. Economic optimization requires explicit tariffs and annual coverage. Archived studies open read-only and inputs migrate to new study IDs.

**Information → Equations** displays the applicable model formulas typeset
offline, including when Qt WebEngine is unavailable. The dashboard opens
after a completed simulation or optimization. For chart editing, the linked
feeder inspector, comparisons and exports, see [Results and dashboards](README_results.md).
