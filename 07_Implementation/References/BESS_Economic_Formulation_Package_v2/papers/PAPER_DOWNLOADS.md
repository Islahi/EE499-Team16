# Paper download manifest

The archive includes the complete change-proposal Markdown file and a **user-supplied excerpt of Table 3**, but it does **not** contain original paper PDF files. External PDF downloads failed from this execution environment. The items below are verified public article/repository locations, not evidence that downloads succeeded.

**On your own internet-connected computer**, run:

```bash
python papers/download_papers.py
```

The script checks each response starts with `%PDF` before keeping it. Failed downloads will not be saved as `.pdf`; open the associated landing page and use its download button if the direct link is blocked.
